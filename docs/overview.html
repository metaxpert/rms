One system, four surfaces

A modular monolith backend feeds a web console, four Flutter apps, and a Python AI service — all sharing one tenant-isolated database.

Backend

NestJS · TypeScript · Postgres
  • 25 tenant tables, all RLS-protected
  • Order → KDS → settle lifecycle
  • Transactional outbox → RabbitMQ
  • Recipe → inventory → COGS → GL
  • Dynamic PRA/FBR fiscal provider

Web console

Next.js · Tailwind · shadcn
  • POS take-order + settle
  • Menu, recipes & modifiers
  • Floor designer (drag)
  • Live KDS board
  • Deliveries & reservations

Mobile

Flutter · 4 native apps
  • Waiter — take & fire orders
  • Manager — live dashboard
  • Driver — GPS + OTP delivery
  • Customer — order & track

AI service

Python · FastAPI
  • Demand forecasting
  • Prep-time prediction
  • Upsell recommendations
  • Service-token secured
